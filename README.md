# Thanach Toey - Portfolio

A professional, modern portfolio website for a Business Development profile, featuring a dark theme and custom typography.

## Features
- **Modern Dark Theme:** A sleek and professional aesthetic.
- **Typography:** Uses the JetBrains Mono font for a clean, developer-friendly look.
- **Sections:**
    - **Hero:** Personal introduction and role.
    - **Projects:** Showcase of key projects (3 placeholders).
    - **Contact:** Easy access to contact information.
- **Responsive Design:** Optimized for various screen sizes.
- **Tech Stack:** HTML5, CSS3, and JavaScript.

## Getting Started

To run this project locally, simply open `docs/index.html` in your web browser.

## Deployment

This project is designed to be hosted on GitHub Pages using the `docs/` folder. To deploy:
1. Push the code to the `master` branch of your GitHub repository.
2. Go to repository **Settings > Pages**.
3. Under **Build and deployment > Branch**, select `master` and then select `/docs` from the folder dropdown.
4. Click **Save**.
5. Your site will be available at `https://thanachtwat.github.io/toey-simple-portfolio/`.
